# 隐私与数据说明

本文说明 WriteRight 当前代码中的主要数据流向，不替代正式法律文本或所部署服务的隐私政策。

## 本地数据

草稿、练习、报告、收藏、记录和偏好使用 SwiftData 等本地机制保存。头像经过缩图与重新编码后仅保存在本机，并按游客或账号空间隔离。

未登录内容留在游客空间，不会在登录时静默并入账号。退出登录或删除账号时，客户端按对应账号边界处理本地内容。

## 账号与云同步

登录使用 Supabase Auth。登录后，为提供跨设备同步和恢复，练习、报告、记录及部分陪伴状态会传输到 Supabase，并通过账号所有权和 Row Level Security 隔离。

云端原稿图片保存在私有存储中，报告回看需要有效账号会话。删除账号应由服务端清理该账号的数据和图片，不能影响其他账号。

## AI 批改

提交批改时，当前选择的题目、作答文字和照片会经 Supabase Edge Functions 发送给 DeepSeek，用于生成评分与反馈。照片直接用于看图批改，不增加独立 OCR 转录步骤。

未提交为批改内容的待办、灵感链接、头像和书桌互动不会仅因保存在 App 中而发送给 AI。AI 模拟估分不等同于正式考试阅卷，看不清的内容不应作为学生错误。

## 小组件与系统展示

记录内容默认不导出到小组件。用户显式开启后，App 才将未完成待办或链接标题写入系统扩展可读的共享空间；正文不进入该快照。关闭共享或切换账号时会更新共享内容。

自选小组件背景保存在本机共享空间。锁屏与灵动岛只展示专注计时所需的信息。

## 密钥与日志

DeepSeek API Key、Supabase secret/service-role key、SMTP 凭据和签名材料不得进入客户端或 Git。开发与服务端日志不应记录完整作文、认证令牌或个人邮箱。

仓库测试使用合成样本。真实个人材料只能放在被忽略的本地目录，不应上传到 Issue、Pull Request 或公开构建日志。
