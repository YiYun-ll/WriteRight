# 组合练习与小组件可靠性（2026-11-06）

## 练习输入和生命周期

小作文、大作文、翻译统一进入练习编辑页。题目（翻译为英文原文）和作答分别选择文字或照片，支持四种组合。切换方式保留本机两种输入，仅把当前选择的内容纳入不可变提交快照；草稿后台保存、删除最后一张照片后的空状态也要保存。文字字段各自拥有焦点；输入时隐藏底部提交栏，键盘提供收起操作。

纯文字走现有文字端点；任一侧包含照片走照片直批端点。照片仍直接交模型，不做OCR、不生成中间转录、不要求核对照片。手工输入的文字是用户原始数据，直接保存到提交快照。图片来源引用只用于最终反馈，不能把无法辨认的内容当成学生错误。

“继续写”只列尚未提交或内容已变更的草稿，菜单提供删除草稿和5秒撤销。“再写一稿”按已有报告对应题目去重，菜单提供“移除再练入口”和撤销：只隐藏本机当前账号的快捷入口，历史报告及提交保留。最近报告和再练入口各最多展示3条，更多内容通过历史查看。报告后可保留题目新开一稿，或保留作答修改重提；已有提交不被覆盖。

## 数据合同与发布顺序

- `DraftDocument.taskInputMode/answerInputMode`为可选兼容字段；旧草稿按已有内容推断。`activePracticeDraft`是仅含选中来源的传输副本，本机未选中的替代输入不丢失。
- `SubmissionDocument.textInputs`和照片请求的`textInputs`为`{task, essay}`。同一侧不能同时提交非空文字和图片；至少有一张图片才走照片端点。题图+文字作答允许`essayImages=[]`。用户文字与照片reference、角色、页码及checksum共同参与幂等指纹；内容改变复用旧键返回409。
- A/B组合照片报告为`2.4.0`，提示词`WRITERIGHT_DIRECT_MIXED_V1`；T组合报告为`3.1.0`，提示词`WRITERIGHT_TRANSLATION_MIXED_V1`。A/B量表保持独立，T仍使用独立15分量表。新报告的`photo_review.text_sources`保存原始手工文字；文字侧页码为null，图片侧只能引用真实来源页。文字作答的逐句ID/原句由程序确定并校验，不伪造全文照片转录。
- 旧纯照片提示词/合同保持，旧报告不重写。修正照片报告应用时参考译文未参与本机指纹校验的问题。重试根据是否存在照片数组识别管线，不能用作答照片是否非空判断。
- 先应用`20261105200000_mixed_practice.sql`，再发布`grading-worker`、`submit-photo-grading`，最后客户端。迁移只扩展service-only入队校验，保留所有权、图片路径和资产绑定约束。

当前开发云EssayPilot-dev已应用迁移，`grading-worker` v12、`submit-photo-grading` v8为ACTIVE；`submit-grading`仍为v8。恢复客户端不能撤回已持久化的组合任务，回退应保留新Worker读取合同，不能直接把Worker降到不理解组合数据的版本。旧客户端不认识T的正式多版本策略仍待完成。

## 自选照片小组件

用户截图为系统灰色占位，没有接收方崩溃日志，不能仅凭截图确认唯一根因。本轮修复代码中发现的内存、尺寸和共享副本风险：

- ImageIO按最大边600px直接缩略解码，保存JPEG不超过180KB，避免先解码整张高分辨率图片；TimelineProvider每个条目只解码一次。背景视图明确约束并裁剪到容器尺寸。
- App Group和接收方共享钥匙串双通道，按更新时间读取最新副本。新背景记录版本化保存，并保留删除墓碑，防止旧副本恢复已移除照片；兼容旧JPEG，损坏副本可回退另一可读副本。钥匙串使用更新后新增，减少删除/新增之间的空窗。
- 仅App私有钥匙串写入不视为共享成功；两条共享路均不可用时给出明确重签权限错误。无可读照片时回退纸色背景。记录快照同样按时间比较，时间相同优先隐私关闭。

模拟器已通过系统相册设置/移除背景、实际SpringBoard添加照片小组件。证据：`artifacts/practice-widget-20261106/widget-custom-photo-real-springboard.png`。接收方仍需用相同签名账号保留WidgetKit扩展和共享权限，覆盖安装后打开App、重新选择照片，并在原反馈手机验证；本轮没有安装或验收该手机，也未完成所有主题/尺寸/内容组合穷举。
