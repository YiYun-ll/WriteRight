## 可以使用吗

**可以尝试这条路线，无需购买Apple Developer Program会员。** 开发者提供WriteRight真机IPA，你在自己的电脑上用iLoader和自己的Apple账户重新签名，安装到连接的iPhone。

iLoader官方支持导入IPA，支持Windows、macOS和Linux；Windows需要iTunes，macOS内置所需设备通信组件。[iLoader官网](https://iloader.app/)、[官方仓库](https://github.com/nab138/iloader)

当前WriteRight最低系统为iOS17.0，18.7.7符合声明，但尚未在你的手机执行安装和完整功能验收。侧载工具能否成功签名还取决于账户、设备信任、网络和Apple服务状态。

## 开始前准备

- 你的电脑和能传数据的USB线。
- 你的iPhone，知道解锁密码，愿意按系统提示完成信任和Developer Mode设置。
- 你自己的Apple账户，能接收两步验证提示。不要向开发者发送密码、验证码或配对文件。
- 开发者发来的 `WriteRight-0.2.0-8-sideload.ipa`；这是等待你重新签名的包，不能直接在“文件”里打开安装。要用主屏幕小组件、锁屏或灵动岛时，用 Sideloadly 安装，不要勾选 Remove Extensions。iLoader 2.4.1 会把小组件套进主应用的描述文件，扩展不会单独生效。
- 可正常联网的电脑与手机。

只从 [iloader.app](https://iloader.app/) 或 [nab138/iloader 的 Releases](https://github.com/nab138/iloader/releases) 下载工具。iLoader会处理Apple账户凭据，应由你本人在自己的电脑里操作；不要在仿冒网站填写账户。Apple签名账户和App里的邮箱账号用途不同。[iLoader官方说明](https://iloader.app/)

## 安装步骤

1. 按电脑平台下载并安装官方iLoader稳定版本。Windows先按官网链接安装所需iTunes；如果无法识别手机，先确认iTunes能识别设备。
2. 将WriteRight的IPA保存到电脑本地。不要改成`.zip`后直接拷进手机，也不要使用其他来源的同名包。
3. 用USB连接iPhone，手动解锁，出现“信任此电脑”时按系统提示确认。
4. 打开iLoader，选择这台iPhone。
5. 在iLoader登录自己的Apple账户，按提示完成验证。没有付费会员也可使用免费开发签名；首次使用可能需要本人处理Apple账户或开发者协议。
6. 只安装主应用、可以不要小组件和灵动岛时，选择导入/安装自选IPA，选中 `WriteRight-0.2.0-8-sideload.ipa`。界面名称以实际稳定版为准；**不需要为了安装WriteRight先安装SideStore或LiveContainer**。要小组件或灵动岛时，改用 [Sideloadly](https://sideloadly.io/) 导入同一份 IPA，不要勾选 Remove Extensions，再用自己的 Apple 账户签名安装。
7. 等待iLoader完成重新签名与安装。若有Bundle ID或证书提示，先记录原文；不要随意切换账户、删除证书或修改应用标识。
8. 在手机“设置 → 通用 → VPN与设备管理”的开发者App中，按提示信任你自己的账户。iOS18可能要求“允许并重新启动”，由你本人确认。
9. 在“设置 → 隐私与安全性 → 开发者模式”按系统提示开启、重启并确认。找不到入口时先确认开发签名App已安装，再按工具/Apple指引排查。
10. 打开WriteRight，到“我的 → 邮箱登录”，用**你自己的邮箱**收验证码并登录。
11. 点击昵称旁铅笔设置昵称；用不含隐私的测试题图、作文图做一次批改。

设备信任与Developer Mode流程可参照[SideStore官方安装文档中的iOS18+步骤](https://docs.sidestore.io/docs/installation/install)及[Apple Developer Mode说明](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)。这里只借用相同的开发签名准备步骤；直接用iLoader装WriteRight无需安装SideStore的LocalDevVPN，也不需要JIT、越狱或关闭系统安全保护。

## 能使用哪些服务

从当前WriteRight代码与配置判断，以下功能不会因为免费Apple签名主动被限制。它们仍需正常网络、有效登录及运行中的云服务；这不是对你的18.7.7设备已完成验收的声明。

| 功能 | 侧载后的条件 |
| --- | --- |
| 邮箱验证码登录、昵称保存 | 使用自己的WriteRight邮箱账号；云端邮件服务可用 |
| 相册/相机上传题图与作文图 | 按需允许系统权限，照片大小/页数满足App限制 |
| AI看图批改、客观估分和报告 | 签名有效、云端函数/队列与模型额度正常；缺题不提供完整任务分数 |
| 逐句修改与理由、进阶建议、双语示范和收藏 | 新报告生成新学习材料；旧报告不会凭空补齐 |
| 练习右上角历史、成绩、同题对比和云同步 | 有相应练习数据；自己的账号只访问自己的内容 |
| 记录待办/短记/链接 | 登录账号下拉同步；点击链接由系统打开，受平台与网络限制 |
| 首页日落、心情回应、陪伴小猫 | 日落与心情为本地功能；登录后小猫的名字与成长随账号云同步，换手机可接着长大（需安装 2026-11-01 第二轮之后的版本），游客只留本机 |

开发者的Mac不用一直开着，你也不用长期连接电脑才能批改。**免费的是开发签名资格；模型调用仍使用开发者已配置的后端额度，不等于无限次免费AI服务。** 如后台暂停、配额耗尽或邮件服务故障，应由开发者处理服务，重装IPA通常没有用。

## 7天续签与后续更新

Apple免费开发描述文件在签发后7天到期，每台设备通常最多安装3个开发签名App。签名过期后App可能无法打开；需要重新签名安装，不是作文记录自动变成无效。[Apple：Personal Team限制](https://developer.apple.com/help/account/basics/about-your-developer-account/)

- 在到期前，用同一个Apple账户、同一个应用标识，通过iLoader重新签名并覆盖安装。先同步/导出重要练习，**不要先卸载App**。
- iLoader直接安装不等于自动续签已启用；先按每周连接自己的电脑续签安排。没有到期恢复/数据保留的实测证据，不承诺所有故障下都无损。
- 开发者提供新IPA时，也用相同账户和标识覆盖安装。更换签名Team、Bundle ID或卸载重装可能导致本机数据/钥匙串登录态不可用。
- 如果想减少连接电脑的次数，可另行研究[SideStore官方安装与续签](https://docs.sidestore.io/docs/installation/install)，它需要额外配置并占用一个开发App名额；本文没有代为配置，也不承诺永久免续签。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 手机不出现 | 检查数据线、解锁/信任、驱动；Windows确认官方要求的iTunes已安装 |
| 提示Apple认证失败 | 核对本人账户、验证提示、网络和账户状态；只分享脱敏错误，不发密码/验证码 |
| 提示App数量或App ID达到上限 | 检查现有开发签名App和免费账户限制；不要反复改Bundle ID消耗更多App ID |
| 提示未受信任开发者 | 核对开发者名称是自己的账户，完成系统信任和Developer Mode |
| 七天后不能打开 | 用原账户/应用标识续签并覆盖安装，先不删除App |
| 安装成功但收不到验证码 | 核对WriteRight邮箱地址、垃圾箱和冷却时间；开发者检查SMTP |
| 验证码发送失败，Safari也打不开云地址 | 先换Wi-Fi/其他网络，再访问下方只读地址对比；安装成功不等于云域名可达，不要反复发送验证码或先卸载App |
| 可以登录但不能批改 | 记录任务错误，由开发者检查云函数、队列和模型额度 |
| 提示最低系统不符或启动闪退 | 提供手机型号、18.7.7、App版本/构建号和脱敏错误；不能只凭最低iOS17声明认定兼容验收通过 |

只读连通地址：[WriteRight云端健康接口](https://tdcxdiqvrfmppaqikgxu.supabase.co/functions/v1/health)。若Safari也报无法打开/丢失连接，说明该手机当前网络到服务地址的链路存在问题；不应只归因于邮箱、iOS版本或侧载。开发者需在实际使用网络验收候选域名/受控网关后再确定长期入口，单纯升级Supabase套餐不直接修复网络可达性。0.1.0构建3增加了区分网络/TLS、频率限制和服务错误的提示，但没有更换云端地址。

## 开发者如何重新生成IPA

本仓库提供可复用命令，在已有Xcode/依赖及本机公开云配置下运行：

```sh
cd /Users/llyy/Desktop/EssayPilot
npm run ios:generate
bash scripts/package-ios-sideload.sh
```

脚本构建真机Release包、检查公开云配置，以 `Payload/EssayPilot.app` 结构生成IPA及SHA-256校验文件，输出在ignored `artifacts/sideload-时间/`。不导出签名私钥，不携带本机用户数据或开发描述文件，不更换已安装App；接收方仍须重新签名。构建成功和IPA结构检查不等于接收方安装成功。
