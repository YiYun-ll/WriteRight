# 进阶反馈、示范作文与记录

更新：2026-10-31。这里描述本轮实现与使用边界，实际验收见 `progress.md`。

## 怎么使用

新批改的「原稿建议」保留必要纠错，随后提供「把句子写得更从容」「让整篇更有方向」两类进阶建议。每条包含具体观察、可参考的英文写法、中文解释和一个小练习。照片引用标明作文页码；读不清的地方不作为学生错误。进阶建议不是要求每句话都变复杂，也不影响原稿评分。

「修改稿」现在有最小修改、表达增强、满分示范三个版本。前两种仍保留学生原意；第三种依据完整题目独立创作，附中文译文、红色重点句和写作思路。复制按钮只复制当前版本的英文，避免把译文和说明混进作文。红色表示值得复习，不表示错误。「满分」是目标档位示范，不承诺真实考试满分。

缺题、关键图表信息不清或作文不可读时，不生成独立示范，不用作文反推题目，也不给完整任务分数。旧报告保持原样；缺少新学习材料时明确说明，不补造内容。

底部导航为：首页、练习、记录、我的。练习右上角的时钟按钮进入「练习历史」，原来的搜索、筛选、成绩、同题对比和报告回看仍在。

「记录」像一本随手记的纸本：待办、短记和灵感链接放在一起。支持新增/编辑、完成与重新打开、日期、置顶、搜索、手边/链接/已完成/全部筛选，以及收起后的撤销。没有打卡排名或逾期羞辱。

点「记下一件事」，在统一编辑页选择灵感链接并粘贴抖音/小红书分享文字，即可保存其中的 HTTPS 地址。首页不再提供独立 Paste 按钮。只保存用户提供的文字和地址，不抓取平台内容、不自动发给 AI。显示实际域名，点击整行后交给系统浏览器或关联 App。具体能否打开目标内容仍取决于平台、登录、原链接和网络。

未登录记录留在本机访客空间；登录后切换到账号自己的记录。访客记录不会静默并入账号，退出后可再看到访客空间。登录后的记录可通过下拉或「我的 → 立即同步」同步，离线编辑先保留本机。当前没有后台实时同步、提醒通知或链接预览抓取。

## 数据与兼容

- 新文字提示词 `WRITERIGHT_GRADING_V1_5`，报告 `1.3.0`；新照片提示词 `WRITERIGHT_DIRECT_VISION_V5`，报告 `2.3.0`。新增 `sentence_reviews`、`advanced_advice` 与 `model_essay`。本轮没有改变评分标尺，A/B 仍分别使用文字 V2、照片 PHOTO_V3 量表。
- 已接受的文字 V1_3/V1_4、照片 V3/V4 作业分别使用冻结的旧提示词和 JSON 合同；更早的旧分流继续保留。原图和历史报告不重写。
- `advanced_advice` 要求可读作文至少覆盖句式与篇章，照片片段引用有效页码，文字片段必须出自原稿。`model_essay` 使用英文、完整中文译文、1–3 个精确且唯一、不交叠的重点引用与中文思路；服务端和原生再次校验重点位置。
- SwiftData `WritingSchemaV4` 通过轻量迁移添加本地记录及独立同步游标，保留旧草稿/报告；关闭自动 CloudKit。导出包含当前账号未删除的记录。
- 云端沿用账号隔离的同步日志/修订机制，新增 `record` 实体。迁移：`20261031010000_notebook_sync.sql`。离线冲突保留另一份记录，不静默覆盖；晚到确认不能清掉上传期间的新编辑。已同步的删除不可复活，撤销会以新 ID 恢复内容。
- 记录使用独立拉取游标从头接续，防止旧客户端跳过不认识的 `record` 后，新客户端漏掉记录。账号删除沿用既有按账号清理，不触碰其他账号。

## 开发云更新

只在取得目标项目的发布授权后执行。先通过检查及迁移测试，再对已连接的开发项目应用迁移与部署函数；不用 dashboard-only SQL，也不重置数据库。

```sh
npm run check
npm test
npm run test:db
node scripts/apply-notebook-cloud-migration.mjs --apply --project-ref YOUR_REVIEWED_LINKED_REF
npx supabase functions deploy submit-grading submit-photo-grading grading-worker --project-ref YOUR_REVIEWED_LINKED_REF --use-api
```

迁移只扩展约束和同步函数，不删除现有行。发布顺序为迁移、函数、新客户端；旧客户端继续工作，无法展示新字段但不应重写历史报告。若客户端回退，新记录暂不显示，应保留云日志和本地数据；不要用数据库重置作回滚。

真实验收需要模型额度，使用一次性合成账号，结束后清理测试私有图与账号。完整模型输出只在 ignored `tests/private/`，公开证据只含检查项，不含邮箱、作文和 token。

```sh
NODE_USE_ENV_PROXY=1 node scripts/test-cloud-bilingual.mjs --live --project-ref YOUR_REVIEWED_LINKED_REF
```

该脚本本轮验证 V5、双语重点、进阶建议、独立示范、记录同步与跨账号隔离，证据写入 `artifacts/cloud-development/acceptance.json`。它证明工程链路，不代表评分准确率或人工满分认定。

## 用户追加：逐句修改

2026-10-31本轮收尾前追加，最终新版本为文字报告1.3.0/提示词V1_5、照片报告2.3.0/提示词V5，量表仍不改变。V1_4/V4作业快照也已冻结，使用各自原合同。

原稿建议新增「逐句修改」：按原稿页序/句序呈现原句、建议写法与具体中文理由，区分需要修改、可选表达、值得保留和需要核对。保留项不改写原句；疑字项不给猜测修改。逐句引用只存在于最终学习报告，不创建转录草稿、OCR调用或中间确认页。

新字段sentence_reviews包含coverage、notice_zh及items，每项包含index、sentence_id、page、original、revised、status、reason_zh。文字源按程序句子ID精确覆盖，原句保持字节，必要修改必须与已有corrections一致；照片源按作文页码顺序，未读清项revised=null且说明疑点。最多40项，较长或不完整报告必须明确标为partial并说明范围，不宣称全篇完成。完整不可读时unreadable且无虚构句子。服务端禁止逐句建议悄悄改数字。

旧报告缺少逐句材料时显示明确提示，原有建议与原图继续可看。新提示词输出预算提高至14000，不改变旧作业的预算/提示词或评分。

## 2026-10-31 统一创建与条目阅读顺序

记录现在按置顶、今天、以后、随记/灵感、已完成分组，只显示非空组。过去的日期保留原日期和「还可以接着做」，不制造逾期惩罚。待办保留复选圆圈；随手记/链接从菜单收好/标记看过，标题正文整块可进入编辑，打开链接独立操作。已完成可从手边页底部找回。卡片省去重复标题和长URL，编辑页仍保留原文。

只有「记下一件事」一个创建入口；灵感筛选下直接创建链接。标题可选，正文第一行或平台来源可自动命名；附加链接不会强制把待办改成链接类别，链接筛选仍能找到它。链接按需展开，支持整段分享文字。保存错误保留输入；成功后清空会遮住新记录的搜索或不匹配筛选。独立剪贴板读取与PasteButton已移除。

撤销删除一律恢复新ID，包括删除尚在同步途中时，防止迟到的删除确认再次隐藏恢复内容。本轮保持既有数据结构与云接口，不需新迁移或部署。
